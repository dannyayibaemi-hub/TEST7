FUO TEST DRILLER — FINAL SOURCE-GUIDED BUILD

2970 objective questions: 90 per topic across 8 MTH 101 topics, 17 PHY 101 topics and 8 CHEM 101 topics.

SOURCE BASIS
The supplied FUO past-question PDF was inspected, including the MTH 101, CHM/CHEM 101 and PHY 101 examination pages. The question bank uses the PDF for terminology, framing, calculation style and topic emphasis. New questions are original/paraphrased and are not copied verbatim. External web research was used only as supplementary syllabus/style context.

AUTH
The dashboard and all practice content are gated behind sign-up/login. Passwords are stored only as SHA-256 hashes in localStorage for this static prototype. This is a client-side gate, not production-grade server authentication. For real accounts, replace the storage adapter with Firebase/Supabase authentication.

FILES
index.html — interface
style.css — responsive design
script.js — question data, authentication, test engine, timer, results and review

RUN
Put all three files in one folder and open index.html. No server is required for the basic version. For GitHub Pages, upload the three files to a repository and enable Pages from the repository settings.
